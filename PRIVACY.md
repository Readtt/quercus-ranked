# Privacy Policy for Quercus Ranked

**Last updated:** 2025-09-27

Quercus Ranked is a browser extension designed for University of Toronto students to view assignment averages in Quercus.

## Data Collection and Use

- **Authentication Information:**  
  The extension temporarily accesses Quercus session cookies in order to fetch data the student is already authorized to view. These cookies are not stored or shared.

- **Website Content:**  
  The extension processes assignment scores and course data from Quercus to calculate anonymized class averages. Only aggregated, non-identifiable data is stored on our servers.

## What We Do Not Collect
We do not collect or store:
- Personally identifiable information (name, email, address, etc.)  
- Health information  
- Financial or payment information  
- Personal communications  
- Web history, browsing activity, or keystrokes  
- Location data  

## Data Sharing
We do not sell or transfer user data to third parties. Data is used only for the single purpose of providing assignment averages and comparisons within Quercus Ranked.

## Open Source
The full source code of Quercus Ranked, including its data handling logic, is open to the public at:  
[https://github.com/Readtt/quercus-ranked](https://github.com/Readtt/quercus-ranked)

## Contact
If you have questions about this privacy policy, please open an issue on the GitHub repository.
